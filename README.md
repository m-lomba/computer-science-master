# Computer Science Master's Degree

Backup repository for all coursework, materials, and projects completed during my Master's Degree in Computer Science at Politecnico di Milano.

## Repository Structure

The repository is organized by academic years, semesters and courses:

```text
.
├── first-year/
│   ├── first-semester/
│   │   └── <course-name>/
│   │       ├── exams/       # Past exam papers and solutions
│   │       ├── utils/       # Lecture notes, summaries, and utilities
│   │       └── ...
│   └── second-semester/
│       └── <course-name>/
├── second-year/
│   ├── first-semester/
│   └── second-semester/
└── <extra-projects>/       # Standalone academic programs (e.g., `asp` for Alta Scuola Politecnica)
